# 🎨 Vincent van Gogh | Painted Experience

A visually immersive one-page website inspired by the life and artwork of **Vincent van Gogh**. The design aims to feel like stepping inside one of his paintings, using rich colours, textured backgrounds, elegant typography, and smooth animations.

## ✨ Features

- 🎨 Artistic landing page inspired by Van Gogh's painting style
- 📖 Brief introduction to the artist
- 🖼️ Gallery showcasing famous masterpieces
- 💬 Iconic Van Gogh quote section
- 📱 Responsive layout for desktop and mobile devices
- 🌙 Elegant glassmorphism navigation bar
- 🎭 Canvas-inspired textured background
- 🎨 Custom typography using Google Fonts
- ⚡ Smooth scrolling navigation

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/yourusername/vangogh-painted-experience.git
```

2. Open the project folder.

3. Launch `index.html` in your preferred web browser.

No installation or dependencies are required.

## 🎨 Design Inspiration

This project was designed to resemble an actual painted canvas rather than a traditional website.

Inspired by:

- expressive brush strokes
- warm golden tones
- deep blues
- museum-style layouts
- Van Gogh's emotional and vibrant artistic style
